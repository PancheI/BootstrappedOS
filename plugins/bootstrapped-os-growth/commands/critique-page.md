---
description: A 3-second test, a hook check and a 4-width screenshot check of a page, then the 3 changes that would most raise sign-ups.
---

Use the `head-of-growth` skill (growth module) on $ARGUMENTS, with the core `browser-checker` agent at 390, 768, 1280 and 1440 px.

**Read first:** `knowledge/brand/brief.md`, `knowledge/pages/home.md`, `knowledge/numbers.md`.

1. **3 seconds, first screen only:** what is it, who is it for, what do I get, what does it cost, what do I click? Any miss is fix #1. Flag lines that are short but need context.
2. **Hook:** is there one big true number? Does the buyer's problem come before the product? Does anything on the page react to the visitor? Any made-up name?
3. **Price:** is the price next to the button, or does a visitor have to leave the hero to find it? Does the checkout show the same price, in words that can't be read two ways?
4. **Above the fold** at each width.
5. **Honesty:** every count is true today; product screens are real.
6. Give the 3 changes that would most raise sign-ups, worst first, one line each, and what each one replaces. If replays exist, run the replay questions first and let them rank the list.
7. For the top change, show **3 options: bold, middle and safe**, and recommend one.

**Hand back:** the screenshots, the 3 changes and the 3 options for the top one. Written to `knowledge/checks/<date>-page.md`. Gates: `shared/gates.md`.
