# Lessons

**Lessons from 114 days and 629 saved corrections and notes, made universal.**

For 114 days the founder ran a one-person business with Claude Code across a dozen projects: a product, a community, outreach, a website, content and launch videos. Every time Claude got something wrong, the correction was saved: 629 notes in all. Rules that repeated were merged. Each lesson shows how many notes backed it, so **(9)** means nine separate notes said the same thing.

## Free in this repo
[`claude-md-starter.md`](claude-md-starter.md): the 15 best-supported rules as one block. Paste it into your `CLAUDE.md`, delete what doesn't fit, and add your own corrections the same way: one rule, one line on why.

## All of them, while you work
The full set (90+ lessons in 9 themes: working with agents, shipping safely, truth and numbers, writing, design, customers and sales, money, video, memory) lives in the Bootstrapped core and keeps growing every week. With the core connected, every role asks `lessons` for the theme it is working on and gets the rules with their reasons. How to connect: [`CONNECT.md`](../../../CONNECT.md).
